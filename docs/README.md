# docs/

Documentation for `Standard DocSet`.

## Internal reference

- `documents_manifest.md` — version index of every tracked doc and code file.
- `folder_structure.md` — authoritative layout.
- `SESSION_OPENER.md` — binding session-start pre-flight (per `CLAUDE.md` Rule 9).
- `SESSION_CLOSER.md` — binding session-end wrap-up (per `CLAUDE.md` Rule 12).
- `standards/` — the adopted standards suite (Standard Set Version v1.0) + `SET_VERSION_ADOPTED.md`.
- `Plans/` — planning documents (all committed; never throwaway, per Rule 1).
- `architecture.md` — the system-design record (the design the engine implements; kept in sync per `CLAUDE.md` § 4).
