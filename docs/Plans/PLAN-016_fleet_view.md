# PLAN-016 — Fleet view: `docs/fleet.csv`, generated and always current

## 1. Goal

One file that shows the whole fleet at a glance, and that is never out of date:
`docs/fleet.csv` — one row per registered project, holding its fixed facts (owner, where it lives,
how it was onboarded, how changes reach it, caveats) and its live standards state (adopted vs vault
Set Version, open log entries, un-landed engine writes, reachability).

"Always current" is met by construction, not by discipline: the file is **generated by the engine**
from the registry (fixed facts) and from live probes (state) — never edited by hand — and it is
regenerated at every point where the fleet can change or be observed: `status` / `drift` / the new
`fleet` command, after every engine write, at session open and close. A pre-push gate fails while
the file disagrees with the registry.

## 2. Operator constraints

**Request (2026-10-04):** "before adding new projects, lets make a csv file that contains all the
information of the fleet, suggest me what must be included in there and make sure the file is always
updated, whenever there is any change."

**Decisions (2026-10-04, answering the posted proposal):**

1. Columns — **approved as proposed** (registry facts / live state / run metadata; § 5e `COLUMNS`).
2. **Not committed** — the file is generated and gitignored (no commit noise; no git history of the
   fleet). Consequence designed in: the push-time gate is LOCAL (CI never has the file → skip there).
3. **Engine-generated** with automatic refresh triggers (not hand-kept + a checklist rule).
4. Location **`docs/fleet.csv`**.
5. Sequencing: the new 780 organization project is added only after this ships ("before adding new
   projects") — it will be the first registry entry written with the full fleet-information keys.

**§ 15.9 intake record.** Step 1: no feature document exists (operator request in chat) — nothing to
preserve. Step 2: investigation = the Phase 0 audit below (live source cited by `file:line`, existing
machinery reused, the design pre-tested on real fleet data in a scratch overlay — numbers, not
plausibility). Step 3, redesign from repo conventions: (a) a hand-kept table drifts — the manifest's
Last-updated block lapsed for 12 versions (L063 class) — so the file is a generated view; (b) the
registry stays the single source of truth for fixed facts (CLAUDE.md § 13): the CSV mirrors it and a
gate fails while they disagree; (c) rollback guarantee: every addition is additive — revert the
commit and delete the file, and every command behaves exactly as before. Step 4: this plan.

**Supersedes:** the hand-kept "Fleet inventory table" in the local `docs/Plans/OPEN_TASKS.md` —
deleted from the register when this ships (local file; no commit).

## 3. Scope summary

**In scope:** a pure `fleet` module (rows, CSV read/render/atomic write, freshness check); optional
fleet-information keys in the registry (validated; unknown keys rejected); one shared probe in the
CLI that feeds `status` / `drift` / `fleet` and the post-write refresh; a local pre-push gate in
`scripts/check_doc_coverage.py`; session opener/closer steps; values for the four registered projects;
D-4 (ssh fail-fast) if approved.

**Out of scope:** the new 780 project's registration (after this ships); a `harvest --project` filter
(queued separately); target-side changes of any kind (nothing is written to any target by this plan);
committing the CSV (decision 2).

### Phase 0 audit findings (2026-10-04, live source at `23d2ef2` + the uncommitted PLAN-011 Phase 3c edits)

- **One probe already exists.** `cli.py:58-73` `_build_statuses` materializes every target once and
  builds the `status` / `drift` rows. It becomes `_probe_fleet`, which also counts the un-landed
  handoff writes — so the table and the CSV come from ONE read of each target (no double probing).
- **Handoff counting already exists.** `sync.py:320-339` `_prior_records` returns how many write
  records an un-landed handoff holds (accumulating / pre-accumulation / unrecognized shapes).
  `handoff_write_count` wraps it — one parser, one truth.
- **The registry ignores unknown keys today.** `registry.py:59-79` `_build_project` reads only the
  connection keys; `load_registry` (`:82-110`) silently accepts anything else (verified by reading
  the code). Once descriptive keys exist, a typo (`ownr`) would silently blank a column → unknown keys
  become a `RegistryError` (D-2). The live registry carries no unknown key (verified).
- **Version labels.** `report.py:76` `_fmt_version` is private; the CSV must print the same labels
  as the table → made public as `fmt_version`.
- **The ssh transport blocks on a down host.** `transport.py:150-160` runs `rsync` with the default
  ssh: a powered-off host costs the ~75 s TCP connect timeout. Measured on the real fleet: a `fleet`
  preview took **1:15** with 780-Automation down; with `-e "ssh -o ConnectTimeout=10 -o
  BatchMode=yes"` the same run took **10.1 s** (openrsync 2.6.9-compatible verified to honor `-e`).
  Because this plan makes probes run more often (session open/close, after every write), D-4 asks
  whether to fix it here.
- **Governance runs in two places.** `scripts/check_doc_coverage.py` (scaffold, 42 lines) runs
  locally before every push (Rule 2) AND in CI (`.gitlab-ci.yml:20-22`, `python:3.11-slim`, the
  package NOT installed, and — by decision 2 — no `docs/fleet.csv`). The gate therefore imports the
  engine only when the file exists, and skips when it is absent in CI (`$CI` is set by GitLab).
- **Machine neutrality.** The folder (and so the CSV) syncs between two Macs whose `$HOME` differs;
  `Project.location` prints the EXPANDED path. The CSV renders a local path under `$HOME` as `~/…`
  so a file generated on one Mac passes the gate on the other.
- **Real-fleet preview (read-only, scratch vault copy):** 4 rows; live columns agree with the facts —
  Capital-Signal `handoff_pending=0` (landed 2026-10-04) and `open_log=1` (its new E002); 780-VPN
  `handoff_pending=2` (its Write 1–2 record); Equinex `open_log=1` (the seed); 780-Automation
  `reachable=no`. Gate: fresh → OK; one registry value edited → exit 1 naming the column; a typo key
  → exit 1 (registry error); file absent locally → exit 1 with the fix; absent with `CI=true` → skip.

def _build_info(name: str, entry: dict[str, object]) -> ProjectInfo:
    """Validate the entry's keys and read its optional fleet information (PLAN-016)."""
    unknown = sorted(set(entry) - set(_CONNECTION_KEYS) - set(_INFO_KEYS))
    if unknown:
        raise RegistryError(f"project '{name}': unknown key(s): {', '.join(unknown)}")
    values: dict[str, str] = {}
    for key in _INFO_KEYS:
        raw = entry.get(key, "")
        if not isinstance(raw, str):
            raise RegistryError(f"project '{name}': '{key}' must be a string")
        value = raw.strip()
        choices = _INFO_CHOICES.get(key)
        if value and choices is not None and value not in choices:
            raise RegistryError(
                f"project '{name}': '{key}' must be one of {', '.join(choices)} (got '{value}')"
            )
        if value and key in _INFO_DATES and not _DATE_RE.fullmatch(value):
            raise RegistryError(f"project '{name}': '{key}' must be a YYYY-MM-DD date")
        if value and key == "onboarded_set" and not _SET_RE.fullmatch(value):
            raise RegistryError(f"project '{name}': 'onboarded_set' must look like v2.7")
        values[key] = value
    return ProjectInfo(**values)

"""The fleet view — one CSV row per registered project (PLAN-016).

docs/fleet.csv is GENERATED: never edited by hand, never committed (gitignored).
Written as UTF-8 with a byte-order mark so spreadsheet apps (Excel) read non-ASCII text

# Live values kept from the previous file while a target cannot be reached.

@dataclass(frozen=True)
class Probe:
    """One target's live reading: its status row, reachability, un-landed handoff writes."""

    status: ProjectStatus
    reachable: bool
    handoff_writes: int | None  # None when the target could not be reached


def _location(project: Project) -> str:
    """Machine-neutral location: a local path under $HOME renders as ~/… (the file is
    folder-synced between machines whose $HOME differs)."""
    if project.transport == "local" and project.path is not None:
        try:
            return "~/" + project.path.relative_to(Path.home()).as_posix()
        except ValueError:
            pass
    return project.location


def registry_columns(project: Project) -> dict[str, str]:
    """The fixed-fact columns for one project, straight from the registry."""
    info = project.info
    return {
        "project": project.name,
        "owner": info.owner,
        "git_remote": info.git_remote,
        "part_of": info.part_of,
        "transport": project.transport,
        "location": _location(project),
        "work_machine": info.work_machine,
        "delivery": info.delivery,
        "onboarding": info.onboarding,
        "onboarded_on": info.onboarded_on,
        "onboarded_set": info.onboarded_set,
        "registered_on": info.registered_on,
        "plan": info.plan,
        "lifecycle": info.lifecycle,
        "caveats": info.caveats,
    }


def _live_columns(probe: Probe, previous: dict[str, str], seen: str) -> dict[str, str]:
    status = probe.status
    row = {
        "vault_set": fmt_version(status.vault),
        "state": status.state.value,
        "reachable": "yes" if probe.reachable else "no",
    }
    if probe.reachable:
        row |= {
            "adopted_set": fmt_version(status.adopted),
            "open_log": str(status.open_entries),
            "handoff_pending": str(probe.handoff_writes or 0),
            "last_seen": seen,
        }
    else:
        row |= {key: previous.get(key, "") for key in _CARRIED}
    return row


def build_rows(
    probes: list[Probe], previous: dict[str, dict[str, str]], as_of: str, vault_sha: str
) -> list[dict[str, str]]:
    """One row per probed project, in registry order; `previous` = the last file's rows."""
    rows: list[dict[str, str]] = []
    for probe in probes:
        project = probe.status.project
        prior = previous.get(project.name, {})
        rows.append(
            registry_columns(project)
            | _live_columns(probe, prior, as_of)
            | {"as_of": as_of, "vault_sha": vault_sha}
        )
    return rows


def read_rows(path: Path) -> dict[str, dict[str, str]]:
    """An existing fleet file's rows keyed by project ({} when absent or unreadable)."""
    if not path.is_file():
        return {}
    try:
        reader = csv.DictReader(io.StringIO(path.read_text(encoding="utf-8-sig")))
        return {
            row["project"]: {k: v or "" for k, v in row.items() if isinstance(k, str)}
            for row in reader
            if row.get("project")
        }
    except (OSError, UnicodeDecodeError, csv.Error):
        return {}


def render_csv(rows: list[dict[str, str]]) -> str:
    """CSV text in the fixed column order; the header row is always present."""
    buffer = io.StringIO()
    writer = csv.DictWriter(buffer, fieldnames=COLUMNS, lineterminator="\n")
    writer.writeheader()
    writer.writerows(rows)
    return buffer.getvalue()


def write_fleet(vault_root: Path, rows: list[dict[str, str]]) -> Path:
    """Atomically replace docs/fleet.csv (a reader never sees a half-written file)."""
    path = vault_root / FLEET_REL
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_name(path.name + ".tmp")
    tmp.write_text(render_csv(rows), encoding="utf-8-sig")  # BOM: Excel reads UTF-8 right
    os.replace(tmp, path)
    return path


def vault_sha(vault_root: Path) -> str:
    """Short HEAD sha of the vault repo ("" when git or the repository is unavailable)."""
    try:
        proc = subprocess.run(
            ["git", "-C", str(vault_root), "rev-parse", "--short", "HEAD"],
            capture_output=True,
            text=True,
            check=False,
        )
    except OSError:
        return ""
    return proc.stdout.strip() if proc.returncode == 0 else ""


def registry_mismatches(vault_root: Path) -> list[str]:
    """Where docs/fleet.csv's registry columns disagree with config/projects.toml ([] = fresh).

    Run by scripts/check_doc_coverage.py before every push; the fix is always to
    regenerate the file (`python -m standard_document_updater fleet`).
    """
    projects = load_registry(vault_root / "config" / "projects.toml")
    rows = read_rows(vault_root / FLEET_REL)
    names = {project.name for project in projects}
    problems = [
        f"{name}: in docs/fleet.csv but not in the registry" for name in sorted(set(rows) - names)
    ]
    for project in projects:
        row = rows.get(project.name)
        if row is None:
            problems.append(f"{project.name}: in the registry but not in docs/fleet.csv")
            continue
        stale = [col for col, value in registry_columns(project).items() if row.get(col) != value]
        if stale:
            problems.append(f"{project.name}: stale column(s): {', '.join(stale)}")
    return problems
